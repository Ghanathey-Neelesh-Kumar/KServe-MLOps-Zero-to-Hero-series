# Contributing

Thanks for helping improve this learning repository.

## Suggested contributions
- Correct inaccurate commands or explanations.
- Improve beginner-facing documentation.
- Add tested troubleshooting steps.
- Report broken links or version incompatibilities.

## Pull request guidelines
1. Explain the problem and proposed change.
2. Keep changes focused on the relevant video or topic.
3. Test commands and YAML against the versions documented.
4. Include verification steps where appropriate.

Never commit credentials, access tokens, private keys, kubeconfig files, or real environment files. Use placeholders in examples.

# Video 02 — KServe Architecture

**How an InferenceService becomes a running model endpoint**

This episode follows the high-level flow from a Kubernetes InferenceService resource to a model-serving workload and an accessible inference endpoint.

## Learning objectives
- Understand the InferenceService custom resource.
- Understand the reconciliation process at a high level.
- Identify the roles of KServe, Kubernetes resources, and serving runtimes.
- Follow how inference traffic reaches the model.

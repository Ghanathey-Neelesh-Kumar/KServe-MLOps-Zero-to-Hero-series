# 🚀 KServe – MLOps Zero to Hero

A practical, beginner-friendly journey into **KServe and Kubernetes-based Machine Learning Model Serving**.

This repository accompanies my KServe YouTube tutorial series, where we explore KServe from its fundamentals and architecture to installation and deploying machine learning models.

The goal is to help beginners understand how modern ML models are deployed, served and managed using Kubernetes and KServe.

## 🎯 Learning Objectives

By following this repository, you will learn:

- Understand KServe and its role in MLOps.
- Explore the KServe architecture.
- Install KServe on a local Kubernetes cluster.
- Understand InferenceService resources.
- Deploy machine learning models.
- Test model inference endpoints.
- Explore scalable model serving on Kubernetes.
